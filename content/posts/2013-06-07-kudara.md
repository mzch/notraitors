ここで朝鮮に目を転じます。三世紀〜七世紀にかけて、朝鮮半島では「[高句麗](https://ja.wikipedia.org/wiki/%E9%AB%98%E5%8F%A5%E9%BA%97)」「[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)」「[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)」が鼎立し、覇を争っていました。最終的に「[白村江の戦い](https://ja.wikipedia.org/wiki/%E7%99%BD%E6%9D%91%E6%B1%9F%E3%81%AE%E6%88%A6%E3%81%84)」で倭・[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)（この時既に[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)は滅亡していたので正確には[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)遺民）連合軍に、[唐](https://ja.wikipedia.org/wiki/%E5%94%90)・[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)連合軍が大打撃を与え、倭はこの敗北から立ち直れないまま、[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)が朝鮮を統一します。この三国の歴史を著したのが『[三国史記](https://ja.wikipedia.org/wiki/%E4%B8%89%E5%9B%BD%E5%8F%B2%E8%A8%98)』です。[高麗](https://ja.wikipedia.org/wiki/%E9%AB%98%E9%BA%97)十七代[仁宗](https://ja.wikipedia.org/wiki/%E4%BB%81%E5%AE%97_(%E9%AB%98%E9%BA%97%E7%8E%8B))の命を受けて[金富軾](https://ja.wikipedia.org/wiki/%E9%87%91%E5%AF%8C%E8%BB%BE)らが編纂しました。この書は[高麗](https://ja.wikipedia.org/wiki/%E9%AB%98%E9%BA%97)が[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)の後継を自任していた上に、編纂者が[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)王室の血を引いていたため、[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)偏重かつ[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)寄りの既述が目立ちます。そのため、その内容を充分に批判することなしに引用することは不用意の誹りを免れ得ません。とはいえ、倭と[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)の激闘の歴史は見て取れますので、倭に関する部分を抜粋して、その様子をうかがうことにしましょう。

なお、「[ひのもとの史記](https://www006.upp.so-net.ne.jp/hinomotoshiki2/)」さんの「[三国史記の倭関連記事](https://www006.upp.so-net.ne.jp/hinomotoshiki2/3/korea3.html)」が一覧表になっていてとても見やすいので、概略を掴むのにはもってこいです。是非ご覧になって下さい。トップページから「[ひのもとの史記・参](https://www006.upp.so-net.ne.jp/hinomotoshiki2/3/index3.html)」をクリックして、左サイドバー内「CONTENTS」の「[三．三国史記](https://www006.upp.so-net.ne.jp/hinomotoshiki2/3/korea3.html)」をクリックすれば見ることができます。

まずは「[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)本紀」から。

<span style="font-size:x-large; color:#000066;">**六年夏五月王與倭國結好　以太子腆支爲質**</span>

<span style="color:#880000">[阿莘王](https://ja.wikipedia.org/wiki/%E9%98%BF%E3%82%B7%E3%83%B3%E7%8E%8B)の六年（西暦397年）、王は倭國と誼を通じた。太子[腆支](https://ja.wikipedia.org/wiki/%E8%85%86%E6%94%AF%E7%8E%8B)を人質とした。</span>

倭と[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)の同盟が成立した、ある意味画期的な事件です。以降、[白村江の戦い](https://ja.wikipedia.org/wiki/%E7%99%BD%E6%9D%91%E6%B1%9F%E3%81%AE%E6%88%A6%E3%81%84)で大敗を喫するまで、倭と[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)は同盟を続けたのです。

<span style="font-size:x-large; color:#000066;">**（阿莘王十一年）五月遣使倭國求大珠**</span>

<span style="color:#880000">[阿莘王](https://ja.wikipedia.org/wiki/%E9%98%BF%E3%82%B7%E3%83%B3%E7%8E%8B)の十一年（西暦402年）、倭國に使いを遣わして大珠を求めさせた。</span>

<span style="font-size:x-large; color:#000066;">**十二年春二月倭國使者至王迎勞之特厚**</span>

<span style="color:#880000">[阿莘王](https://ja.wikipedia.org/wiki/%E9%98%BF%E3%82%B7%E3%83%B3%E7%8E%8B)の十二年（西暦403年）、 倭國が使者を派遣してきた。王はこれを迎えて労い、特に厚く遇した。</span>

倭と百済の紐帯が固いことを示す記事が続きます。

<span style="font-size:x-large; color:#000066;">**十四年王薨王仲弟訓解攝政以待太子還國季弟禮殺訓解自立爲王腆支在倭聞訃哭泣請歸倭王以兵士百人衛送既至國界漢城人解忠來告曰大王棄世王弟禮殺兄自王願太子無輕入腆支留倭人自衛依海島以待之國人殺禮迎支即位妃八須夫人生子久尒辛**</span>

<span style="color:#880000">[阿莘王](https://ja.wikipedia.org/wiki/%E9%98%BF%E3%82%B7%E3%83%B3%E7%8E%8B)の十四年（西暦405年）、王が薨じた。王の次弟、訓解が摂政し、太子が国に帰るのを待った。末弟、禮が訓解を殺して、自立して王となった。[腆支](https://ja.wikipedia.org/wiki/%E8%85%86%E6%94%AF%E7%8E%8B)は倭にあって訃報を聞き、哭泣して帰国を願った。倭王は兵士百人を護衛に付けて送らせた。国境に至ろうとした時、漢城人の解忠が来てこう言った「大王が世をお棄てになり、王弟の禮が兄を殺して自ら王になりました。太子が軽々に入国されないことを願います」[腆支](https://ja.wikipedia.org/wiki/%E8%85%86%E6%94%AF%E7%8E%8B)は倭人を留め自らを護衛させた。海島により知らせを待った。国人が禮を殺して、[腆支](https://ja.wikipedia.org/wiki/%E8%85%86%E6%94%AF%E7%8E%8B)を迎え即位した。妃の八須夫人が王子久尒辛を産んだ。</span>

簒奪を計った王の末弟を諸豪族が殺して、倭から太子を迎え、王とする話です。倭は太子に護衛を付けて送り届けています。

<span style="font-size:x-large; color:#000066;">**五年倭國遣使送夜明珠**</span>

<span style="color:#880000">[腆支王](https://ja.wikipedia.org/wiki/%E8%85%86%E6%94%AF%E7%8E%8B)の五年（西暦410年）、倭國に使いを遣わし、夜明珠を送った。</span>

<span style="font-size:x-large; color:#000066;">**十四年夏遣使倭國送白綿十匹**</span>

<span style="color:#880000">[腆支王](https://ja.wikipedia.org/wiki/%E8%85%86%E6%94%AF%E7%8E%8B)の十四年（西暦419年）、十四年夏、倭國に使いを遣わし、白絹十匹を送った。</span>

なので、倭に恩義を感じたのか、腆支王は贈り物をしています。倭・百済同盟は順調です。

<span style="font-size:x-large; color:#000066;">**二年春二月王巡撫四部賜貧乏穀有差倭國使至從者五十人**</span>

<span style="color:#880000">毗有王二年春二月（西暦427年）、王は四方を巡撫し、貧乏な者にはその程度に応じて穀物を授けた。倭国の使者が従者を五十人引き連れてやって来た。</span>

代が変わっても倭との同盟が継続している様子が窺えます。

<span style="font-size:x-large; color:#000066;">**（武王）九年春三月遣使入隋朝貢隋文林郞裴淸奉使倭國經我國南路**</span>

<span style="color:#880000">武王の九年（西暦608年）春三月、使いを遣わして隋に朝貢した。隋の文林郞、裴淸が倭國へ使いを奉り、我が国の南路を通った。</span>

ここで記事は七世紀に飛びます。隋の裴世清が遣隋使の答礼に倭へ赴く際、百済を通ったことがわかります。つまり、倭・百済同盟は続いているのです。

<span style="font-size:x-large; color:#000066;">**（義慈王）十三年春大旱民饑秋八月王與倭國通好**</span>

<span style="color:#880000">[義慈王](https://ja.wikipedia.org/wiki/%E7%BE%A9%E6%85%88%E7%8E%8B)の十三年春（西暦653年）、旱がひどく、民が飢えた。秋八月、王は倭國と通好した。</span>

百済最後の王、[義慈](https://ja.wikipedia.org/wiki/%E7%BE%A9%E6%85%88%E7%8E%8B)王です。国際関係は緊張を増していました。[隋](https://ja.wikipedia.org/wiki/%E9%9A%8B)が滅び、[唐](https://ja.wikipedia.org/wiki/%E5%94%90)が建国されたのですが、[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)はその[唐](https://ja.wikipedia.org/wiki/%E5%94%90)と同盟を結び、[高句麗](https://ja.wikipedia.org/wiki/%E9%AB%98%E5%8F%A5%E9%BA%97)と[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)を脅かしていました。[高句麗](https://ja.wikipedia.org/wiki/%E9%AB%98%E5%8F%A5%E9%BA%97)にはかつての栄光はなく、両国とも押され続けています。[義慈王](https://ja.wikipedia.org/wiki/%E7%BE%A9%E6%85%88%E7%8E%8B)は、倭との盟いを新たにする必要を覚えたのでしょう。しかし、その盟いも虚しく、西暦660年、[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)は[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)に滅ぼされてしまいます。

<span style="font-size:x-large; color:#000066;">**龍朔二年七月（前略）時福信既專權、與扶餘豊相猜忌。福信稱疾、臥於窟室、欲俟豊問疾執殺之。豊知之、帥親信、掩殺福信。遣使高句麗倭國乞師、以拒唐兵。孫仁師中路迎撃破之、遂與仁願之衆相合、士氣大振、於是諸將議所向。或曰、加林城水陸之衝、合先撃之。仁軌曰、兵法避實撃虚、加林嶮而固、攻則傷士。守則曠日、周留城百濟巣穴、羣聚焉。若克之、諸城自下。於是、仁師仁願及羅王金法敏帥陸軍進、劉仁軌及別帥杜爽扶餘隆帥水軍及粮船、自熊津江往白江、以會陸軍、同周留城。遇倭人白江口、四戰皆克。焚其舟四百艘、煙炎灼天、海水爲丹。王扶餘豊脱身而走、不知所在。或云奔高句麗。獲其寶劒。王子扶餘忠勝忠志等帥其衆、與倭人並降。獨遲受信據任存城未下。**</span>

<span style="color:#880000">龍朔二年（西暦662年）七月、（前略）時に福信が権力を専横し、扶餘豊とは互いに猜疑し嫌い合っていた。福信は病と称して窟室に伏して、豊が見舞いに来ることを期待し、その時に捉えて殺してしまおうと考えていた。豊がこれを知り、信頼の置ける者たちを率いて福信の不意を突いて殺した。高句麗と倭国に使いを遣わして軍の出動を願い、唐の軍を攻めた。（唐・新羅軍の）孫仁師は中路で迎撃しこれを破り、遂に仁願の軍衆と見え、士気がすこぶる高まった。ここにおいて（唐・新羅軍の）諸将は会議で結論したところへ向かった。或いは曰く、加林城は水陸の要衝なのでまずこれを攻撃して下すべきだと。仁軌は「兵法は実を避け虚を撃つものだ。加林城はなおも守備が固く、攻めても兵を消耗するだけだ」と言った。守則曠は「周留城は百済の巣穴だ。ただ群がり集まっているだけではないか。もしこれに勝つことができれば、他の城は自ずから下ってくるだろう」ここにおいて仁師仁願と新羅王、金法敏は陸路を取り軍を進めた。劉仁軌と別働隊の杜爽、扶餘隆は水軍と軍資を積んだ船を率いた。熊津江より白江に至り、陸で軍を併せ、周留城を下した。（唐・新羅軍は）倭人と白江の港で会戦し、四戦して四勝した。倭の船四百艘を焼き、その煙と炎は天を焦がし、海水を赤い色に変えた。百済王の扶餘豊は脱出して逃走し、所在がわらなくなった。或いは高句麗に逃げたとも伝える。百済の宝剣を奪い取り、百済王子の扶餘忠勝と忠志らはその軍衆を率いて、倭とともに並んで（唐・新羅軍に）降伏した。遲受信は単独で任存城に拠っておりまだ下っていなかった。</span>

そして、西暦663年、ついに[白村江](https://ja.wikipedia.org/wiki/%E9%8C%A6%E6%B1%9F_(%E9%9F%93%E5%9B%BD))で、倭・[百済](https://ja.wikipedia.org/wiki/%E7%99%BE%E6%B8%88)遺民連合軍と[唐](https://ja.wikipedia.org/wiki/%E5%94%90)・[新羅](https://ja.wikipedia.org/wiki/%E6%96%B0%E7%BE%85)連合軍が雌雄を決しますが、倭は大敗を喫します。倭はこの痛手からついに立ち直れませんでした。
